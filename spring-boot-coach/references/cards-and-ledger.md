# 防忘卡与错题账 — Retention System

他的核心症状："学过就忘"。本文件把"不忘"变成机制，不靠意志力。

## 防忘卡格式（问诊/伴读每关必产）

```markdown
C<编号> | 主题: <节点/异常名> | 出自: <工程路径或黑马章节>
Q: <用他真实会遇到的形式问："启动报 X，第一步看什么？">
A: <≤3 行，指向最小的可执行动作，如"看 bean 包是否在启动类包及其子包下；--debug 看 Negative matches">
卡来源: <哪次问诊/哪一章> | 崩过次数: 0
```

规则：
- 卡的答案必须是**动作**（看哪、跑什么命令），不是概念定义。
- 一张卡只考一个动作；大知识拆小（"读栈"和"查来源"是两张卡）。
- 卡随工程走：答案里引用的工程/命令必须是他机器上真有的。

## 复习排期（遗忘曲线）

- 新卡：当天 D+0 出，D+1 复习，D+3 复习，D+7 复习；三次都对 → 进月度池。
- 复习方式：**口述 + 敲最小工程**：让他先讲卡答案，再在电脑上把对应最小工程跑一遍（30 秒也算）。
- 崩一次 → 打回 D+1 重排；**同一张卡崩两次 → 触发降级**：回到反魔法序列对应级（knowledge-map.md），重敲最小工程，本周复盘会上他只讲工程不讲概念。

## 错题账（每关必记，一行一条）

```markdown
R<编号> | <日期> | 症状: <异常/现象一句话> | 根因: <一环：扫描/条件/注入点/代理/环境> | 用了哪件工具: --debug | /beans | 读栈 | 断点 | 关联卡: C<n> | 关联节点: <反魔法序列级>
```

规则：
- 复盘会先读账不读卡：账是地图上的伤口分布，哪类根因出现 ≥3 次 → 那一整块知识降级重讲，而不是继续出新卡。
- 工具维度单独统计：如果他连续三次不用 `--debug`，下次问诊直接带跑，不问他会不会。
